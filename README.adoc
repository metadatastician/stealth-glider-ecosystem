_Coordination hub for the Stealth Glider line: holds the canonical seven-stage chain, the membership manifest and the series roadmap. Manifest only; the games live in their own repositories._

The Stealth Glider line is a series of increasingly demanding investigations
into interactive experiences that stay mathematically lawful under Conway's
Game of Life. Each investigation is its own repository. This hub holds only
what the line shares.

== The line

f19-stealth-glider -> f117a-stealth-glider -> sr71-blackglider -> x15-rocket-glider -> planer-1 -> enterglide-ncc-137-k -> tardis-rule-disruption

`machine-readable/descriptiles/ECOSYSTEM.a2ml`.

== Owned here

* The canonical chain string. Every member's own ECOSYSTEM.a2ml carries it
  verbatim and names this repository as `coordination`.
* The membership manifest and `scripts/check-membership.sh`, which checks
  the manifest offline and then every member repository on GitHub.
* The series roadmap, `docs/status/ROADMAP.adoc`, including the recorded
  definition of TARDIS.

== Not owned here

* Any game's semantics, code, proofs or specification. Each member is
  canonical for itself (ANCHOR `authority = "upstream-canonical"`).
* The estate registry. Clade registration lives in gv-clade-index.
* Member source trees. This hub is manifest-only: no submodules, no vendoring.

== Gates

`just test` runs the placeholder check, the root-shape check and the offline
membership negative control. The `anchor-drift` workflow additionally runs the
remote membership check and is red until all seven members are published.
